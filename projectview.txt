build docker image: docker build -t mlops-docker-demo (name of the image)

run the container: docker run -p 5000:5000 mlops-docker-demo

Tag your image: docker tag mlops-docker-demo {docker userid}/mlops-docker-demo:v1

push image to dockerhub: docker push {docker userid}/mlops-docker-demo:v1

pul image from dockerhub: docker pull {docker userid}/mlops-docker-demo:v1
